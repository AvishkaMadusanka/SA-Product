🍰 SA Product Website (With Admin Panel)
📌 About the Project

This is a Cake Ordering Website where customers can browse cakes, view details, and place orders online. The system also includes a powerful Admin Panel for managing the entire platform efficiently.

🚀 Features

👤 User Side
Browse different types of cakes
View cake details (price, description, images)
Add cakes to cart
Place online orders easily
Responsive and user-friendly UI

🛠️ Admin Panel
Add / Update / Delete cake products
Manage customer orders
View order status (Pending / Processing / Delivered)
Manage users (if applicable)
Dashboard with summary (orders, products, revenue)
Secure login for admin access only

🧑‍💻 Technologies Used
HTML, CSS, JavaScript (Frontend)
PHP
MySQL (Database)
Bootstrap (UI design)

🔐 Admin Panel Access

Admin panel is restricted to authorized users only.

Admin can:

Control all product data
Monitor orders
Manage website content

📊 Project Purpose

This project is built to simplify online cake ordering system management and provide a smooth experience for both customers and administrators.
